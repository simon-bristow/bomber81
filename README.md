# Bomber 81

A browser remake of the 1982 Sinclair ZX81 game *Bomber*. Your plane drops one row every time it crosses the screen. Bomb the skyscrapers flat, one bomb at a time, then land on the empty street.

**Play:** https://simon-bristow.github.io/bomber81/

## Controls
- **Space / tap**: drop a bomb
- **C**: switch between ZX81 black-and-white and colour
- **M**: sound on/off

Everything lives in a single `index.html`, with no build step.
